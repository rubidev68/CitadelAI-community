# Documentation Scope

**Date:** 2026-01-05  
**Status:** ✅ Defined

---

## Scope Definition

The documentation website at `docs.citadelai.app` is **exclusively** for the **Community Edition** (open-source).

### ✅ What is Documented

- **Community Edition Usage** - How to use the open-source Community Edition
- **Community Edition Architecture** - System architecture of Community Edition
- **Contributing to Community Edition** - Guidelines for contributing open-source code
- **Migration Process** - How improvements are migrated FROM Business Edition TO Community Edition (for maintainers)

### ❌ What is NOT Documented

- **Business Edition Features** - Proprietary features are not documented
- **Business Edition Usage** - Business Edition has separate documentation
- **Proprietary Integrations** - Slack, Teams, Google Drive, OneDrive, etc.
- **Subscription/Billing** - Not applicable to Community Edition
- **Enterprise Features** - Not available in Community Edition

---

## Documentation Principles

1. **Open-Source Focus** - All documentation is for the open-source Community Edition
2. **Contributor-Friendly** - Clear guidelines for open-source contributions
3. **No Business Traces** - No references to proprietary features or services
4. **Community-First** - Documentation helps the open-source community

---

## Content Guidelines

### ✅ Include
- Community Edition features
- Open-source integrations (Nextcloud)
- Core functionality
- Contributing guidelines
- Architecture overview (Community Edition)
- Migration process (for maintainers)

### ❌ Exclude
- Business Edition features
- Proprietary integrations
- Subscription/billing information
- Enterprise features
- Business-specific workflows

---

## Target Audience

- **Open-source users** - People using Community Edition
- **Contributors** - People contributing to Community Edition
- **Maintainers** - People maintaining the migration process
