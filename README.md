# CitadelAI Community Edition

CitadelAI Community Edition is an open-source, AI-powered chatbot platform.

## 🚀 Features
*   **Visual Block Editor**
*   **Multi-Model Support**
*   **Web Crawling**
*   **Role-Based Access**
*   **Open Source**

## 🛠 Prerequisites
*   Docker & Docker Compose
*   Git

## 🏁 Quick Start
1.  **Clone:** `git clone https://github.com/rubidev68/citadelai-community.git`
2.  **Config:** `cp .env.example .env`
3.  **Run:** `docker-compose up -d`
4.  **Access:** Admin (http://localhost:3000), User (http://localhost:4000)
